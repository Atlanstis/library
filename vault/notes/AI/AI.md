# AI

本目录整理 AI 相关知识、工具使用方法与实践经验，当前从 Skills 主题开始积累。

## 主题入口

- [[Skill 推荐清单]]：当前推荐的 Skills 相关项目与工具的用途、来源及使用说明入口。

## 当前目录

以当前 `AI/` 目录为起点，目录结构如下：

```text
AI/
├── AI.md
└── Skills/
    └── Skill 推荐/
        ├── Skill 推荐清单.md
        ├── 开发流程/
        │   └── OpenSpec/
        │       ├── OpenSpec 使用说明.md
        │       └── OpenSpec 维护记录.md
        └── 代码实践/
            └── Vue Skills/
                ├── Vue Skills 使用说明.md
                └── Vue Skills 维护记录.md
```

## 命名与扩展约定

- 通用技术术语保留英文，例如 `AI`、`Skills`；知识分类使用中文。
- 使用说明保留工具或项目原名，例如 `OpenSpec 使用说明`、`Vue Skills 使用说明`。
- Skills 推荐对象按项目建立文件夹，使用说明与维护记录同级存放；使用说明负责操作流程，维护记录负责依据、版本快照与维护历史，两者互相链接。
- 有实际笔记时再新增主题目录，例如基础概念、模型与工具、提示词、工作流与实践。
- 单个主题先用一篇笔记承载；形成多篇独立内容后，再为该主题建立子目录，并同步更新导航。

## 文件归属

整理后的笔记保存在本目录；临时记录先放入 `vault/inbox/`。图片、PDF 等附件保存在 `vault/attachments/`，可复用笔记模板保存在 `vault/templates/`。
